# Фаза 2 — Фильтр звонков

Статус: ⬜ · Начата: — · Завершена: —

Кратко. Детализируем по шаблону `_TEMPLATE.md`, когда фаза станет следующей.

## Цель

Незнакомые номера обрабатываются по выбранному режиму без того, чтобы Syto была
звонилкой по умолчанию: `CallScreeningService` + `ROLE_CALL_SCREENING`.

## Гейт G2

Неделя на телефоне пользователя: ни одного пропущенного звонка от контакта,
все незнакомые обработаны по режиму.

## Наброски подфаз

- 2.1 `ContactResolver`: поиск по `ContactsContract.PhoneLookup`, кэш в памяти, нормализация номеров (E.164, локальные форматы UA).
- 2.2 `SytoScreeningService`: режимы allow / silence / reject / reject + SMS для незнакомых. Запрос роли.
- 2.3 Исключения: короткие и сервисные номера, скрытый номер.
- 2.4 Журнал в файл (до фазы 4) и минимальный экран режима.
- 2.5 Связка с голосом (если G1 = Go): режим «передать боту» = не блокировать в screening, а обработать в `InCallService`.

## Зависимости

Фаза 0. Результат G1 влияет на 2.5.
