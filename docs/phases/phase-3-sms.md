# Фаза 3 — SMS-автоответ

Статус: ⬜ · Начата: — · Завершена: —

Кратко. Детализируем, когда фаза станет следующей.

## Цель

На SMS от незнакомого отправителя уходит шаблонный ответ, не чаще одного раза
на номер за настраиваемое окно, никогда — на короткие и сервисные номера.

## Гейт G3

Неделя на телефоне: ноль ответов сервисным номерам, ноль дублей, ответы уходят только незнакомым.

## Наброски подфаз

- 3.1 `SmsReplyReceiver` на `SMS_RECEIVED`, разрешения `RECEIVE_SMS`, `SEND_SMS`.
- 3.2 `ReplyThrottle`: окно на номер, фильтр коротких номеров и alphanumeric-отправителей.
- 3.3 Шаблон ответа, настройка, ответ на «отклонить + SMS» из фазы 2.
- 3.4 Проверка на реальном трафике.

## Зависимости

Фаза 2 (понятие «незнакомый», `ContactResolver`). Play Store не цель, sideload (см. README).
