# Фаза 4 — Хранилище и UI

Статус: ⬜ · Начата: — · Завершена: —

Кратко. Детализируем, когда фаза станет следующей.

## Цель

Всё, что приложение сделало, видно в UI; всё, что оно делает, настраивается в UI.
Room вместо файлов, Compose-экраны, экспорт.

## Гейт G4

Пользователь неделю пользуется только через UI, не заглядывая в логи и настройки в коде.

## Наброски подфаз

- 4.1 Room: таблицы звонков, SMS-ответов, расшифровок, правил. Миграция журналов из файлов не нужна, спайковые логи выбрасываем.
- 4.2 Экраны: главный (статус и режим), история, детали звонка с расшифровкой, настройки.
- 4.3 Экспорт JSON / CSV через `ACTION_CREATE_DOCUMENT`, очистка.
- 4.4 Онбординг: разрешения и роли с объяснениями.

## Зависимости

Не блокирует 2, 3, 5. Делаем, когда файловые логи начинают мешать.
