## Цель

Из спайка — продукт: стабильный, настраиваемый, с честной инструкцией об ограничениях.

## Гейт G5

Недельный полевой тест у пользователя и хотя бы у одного стороннего тестера на другом OEM.

## Наброски подфаз

- 5.1 Переписать `voice` по итогам D-004: чёткие границы `CallSession` / `Talker` / `Listener` / `DialogMachine`, тесты машины диалога без устройства.
- 5.2 Загрузчик модели Vosk: один опциональный сетевой вызов с GitHub Releases, проверка хэша, без `INTERNET` в основном варианте сборки не обойтись — решение записать в `DECISIONS.md` (отдельный флейвор или явное разрешение).
- 5.3 Языки: uk / ru / en, выбор в настройках, TTS-голоса.
- 5.4 Редактор правил диалога: ключевые слова → ответ → действие (положить трубку / передать / попросить SMS).
- 5.5 Расшифровки в истории (фаза 4), уведомление после звонка с краткой сводкой.
- 5.6 Правовое: обязательное объявление о записи, ссылка на README про местные законы.
